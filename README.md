A multi-page learning blog (home, about and post pages) about my move from the Frontend Developer Career Path to a coding bootcamp.

**Live demo:** [https://journal-learning.netlify.app](https://journal-learning.netlify.app)

## Getting started

Install the dependencies and run the project:

```
npm install
npm start
```

## Built with

HTML, CSS and JavaScript, bundled with [Vite](https://vitejs.dev/).
